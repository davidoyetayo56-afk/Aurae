# AURAÈ Storefront

A considered streetwear storefront for AURAÈ. The site is a responsive, single-page storefront with a product bag, quantity controls, and WhatsApp order enquiries.

## Build

Run `npm run build`. The build verifies the three provided mannequin images with SHA-256 checksums, assembles the two segmented WebP assets, and creates the production site in `dist/`.

Product prices are intentionally not fabricated. Orders are sent to WhatsApp so AURAÈ can confirm current prices and availability.
